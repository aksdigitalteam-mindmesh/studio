# FitBoost App Screenshots (Android Perspective)

This document provides a visual overview of the key screens in the FitBoost application as they would appear on a typical Android device.

## 1. Main Dashboard

The central hub for the user's daily activity, showing calorie intake, macros, and quick access to tracking.
